# CS 340 – Client/Server Development

## Project Overview

In this course, I developed a database-driven dashboard for Grazioso Salvare, an organization that identifies dogs suitable for search-and-rescue training. The project involved using MongoDB to manage animal shelter data, Python to perform CRUD operations, and the Dash framework to create an interactive dashboard.

The completed dashboard allows users to filter animal records, view information in an interactive data table, and examine animal locations through a geolocation chart. This project helped me develop my database management, Python programming, and client/server application development skills.

## How do you write programs that are maintainable, readable, and adaptable?

When writing programs, I focus on keeping my code organized, readable, and easy to modify. I use meaningful variable names, comments when necessary, and separate functions to handle different responsibilities. In Project One, I developed a Python CRUD module that allowed my application to communicate with MongoDB. I reused this module in Project Two to connect my dashboard to the database.

One major advantage of this approach was that I did not have to rewrite the database connection and query functionality when developing the dashboard. Separating database operations from the user interface made the application easier to maintain and troubleshoot. In the future, I could reuse or expand this CRUD module for other applications that require database management, such as inventory systems, employee databases, or customer management applications.

## How do you approach a problem as a computer scientist?

When approaching a problem, I begin by reviewing the requirements and breaking the project into smaller, manageable tasks. For the Grazioso Salvare project, I first needed to understand the animal shelter data and determine how MongoDB queries could identify dogs suitable for different rescue training categories. After developing the database functionality, I focused on connecting the data to an interactive dashboard.

This project differed from many of my previous programming assignments because it required multiple technologies to work together. Instead of developing a single program, I had to integrate MongoDB, Python, and Dash into one functional application. I also had to consider the needs of a specific client rather than simply meeting technical requirements.

In future projects, I would continue using a step-by-step development process that includes analyzing requirements, designing database structures, testing queries, and validating functionality. I would also communicate with clients to ensure the final application meets their expectations.

## What do computer scientists do, and why does it matter?

Computer scientists use technology, programming, and problem-solving skills to develop solutions that improve how people and organizations operate. They design software, manage data, develop algorithms, and create systems that make tasks more efficient and reliable.

My work on the Grazioso Salvare dashboard demonstrates how computer science can help organizations make better decisions. By creating a dashboard that organizes animal shelter information and allows users to filter records based on rescue training requirements, I made it easier to identify potential search-and-rescue dogs. Instead of manually searching through large amounts of data, users can quickly access relevant information through an interactive interface.

Projects like this demonstrate the importance of computer science because they show how technology can save time, improve accuracy, and support meaningful work. This experience strengthened my understanding of how software development can solve real-world problems and provide value to organizations.
